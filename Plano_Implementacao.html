Revisão de Documento Estratégico
🎯 Visão e Objetivos do Projeto

Objetivo Principal

Habilitar a plataforma Salesforce Marketing Cloud como canal unificado de comunicação digital, integrando Email, SMS e WhatsApp com dados centralizados no Data Cloud via Azure Blob Storage, permitindo jornadas personalizadas em escala com inteligência Einstein.

Objetivos Específicos

  • Provisionar e configurar o ambiente SFMC (BU, IPs, domínios, canais) em até 30/11
  • Integrar Azure Blob Storage ao Data Cloud para ingestão e unificação de dados de clientes
  • Habilitar os 3 canais de comunicação: Email (23/11), SMS e WhatsApp (19/11)
  • Lançar a jornada piloto "Limite de Crédito" em 23/12 com mínimo 1 canal ativo
  • Habilitar features Einstein: STO, Engagement Scoring e Messaging Insights
  • Garantir conformidade com LGPD em todos os canais e jornadas

Escopo

  • In Scope: SFMC (Email, SMS, WhatsApp), Data Cloud (2 Data Spaces, Identity Resolution, Segmentação), Personalization server-side (1 área de conteúdo no app), Azure Blob Storage connector, Einstein STO / Engagement Scoring / Messaging Insights
  • Out of Scope: CRM (Salesforce Sales/Service Cloud), integração com ERPs, web tracking via beacon JavaScript, outros canais (push notification, in-app messaging nativo)

🚨 Pontos Críticos — UC1 Limite de Crédito

Três dependências que, se atrasarem, impactam as atividades listadas em cada caixa.

CRÍTICO 1

Integração de dados

Conexão técnica entre o Azure Blob Storage e o Data Cloud (connector, credenciais e permissões IAM), necessária para o segmento de entrada da UC1.

Atividades dependentes:
Fundação e Setup
  • Configuração do connector Azure Blob Storage no Data Cloud
  • Fornecer credenciais Azure (Storage Account, SAS Token, Container, schema)
  • Configurar permissões de acesso no Azure (IAM / SAS Token com leitura)
  • Integração de bundles no Data Cloud (SFMC, Personalization, Azure)
Data Cloud — Ingestão e Unificação
  • Configuração dos Data Streams a partir do Azure Blob Storage
  • Mapeamento dos campos para DMOs
  • Ativação dos segmentos para o SFMC via Data Cloud Connector
UC1 — Limite de Crédito
  • Criação da jornada — Entry via Segment Activation do Data Cloud
CRÍTICO 2

Disponibilização de dados

Dados do cliente disponíveis, com qualidade e schema acordados, para ingestão no Data Cloud. Sem eles não há unificação nem segmento para a UC1.

Atividades dependentes:
Data Cloud — Ingestão e Unificação
  • Disponibilização dos arquivos no Azure Blob Storage (até 04/12)
  • Configuração dos Data Streams (batch/scheduled)
  • Mapeamento dos campos para DMOs (Individual, Contact Point Email, Phone)
  • Configuração de Identity Resolution (email, CPF, phone)
  • Criação dos primeiros Segments no Data Cloud
  • Publicação dos segmentos como Data Extensions no SFMC
UC1 — Limite de Crédito
  • Ingestão de dados do caso de uso 1 (até 08/12)
  • Criação da jornada — Entry via Segment Activation do Data Cloud
  • Teste em Test Mode
  • Ativação para grupo reduzido (soft launch)
CRÍTICO 3

Habilitação de um canal

Canal Email habilitado (domínio, IP e templates) para que a UC1 possa disparar o D+0 e o repique.

Atividades dependentes:
Email
  • Setup de domínio de envio e autenticação (SPF, DKIM, DMARC)
  • Configuração de SAP e IPs dedicados
  • Criação de templates de email
  • Planejamento de IP Warming
UC1 — Limite de Crédito
  • Configuração de 1 canal com repique — Email D+0
  • Ativação para grupo reduzido (soft launch — Email)
  • Monitoramento: bounce, deliverability, opt-out
Escopo desta entrega (30 dias): ativação e configuração das plataformas para suportar a primeira jornada operacional (UC1 — Limite de Crédito, Go-Live 23/12). Itens marcados como opcional dependem de validação comercial de licença ou prioridade do projeto.
